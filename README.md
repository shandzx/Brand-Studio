# Brand Studio Database Assignment

## 📌 Overview

This project is a SQL database designed to manage a brand studio’s operations, including clients, services, projects, and payments.

## 🧱 Database Structure

The database includes the following tables:

* **clients** – stores client details
* **services** – stores services offered
* **projects** – links clients to services
* **payments** – tracks payments for each project

## 🔗 Relationships

* Each project is linked to a client and a service
* Each payment is linked to a project

## 🔍 Key Features

* Use of primary and foreign keys to maintain relationships
* Multiple queries including JOINs, aggregates, and filtering
* Stored procedure to filter projects by status

## ▶️ How to Run

1. Open the SQL file in DBeaver or MySQL
2. Run the script step by step
3. Execute the SELECT queries to view results
